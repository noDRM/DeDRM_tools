FileOpen ineptpdf 10.3.0
-----------------------

This Windows-only standalone tool handles Adobe ADEPT and FileOpen-protected
PDF files. It requires Python 3, requests, pycryptodome (or pycryptodomex), and
pywin32.

The historical FileOpen request remains the default:

    py -3 ineptpdf_fileopen.pyw - protected.pdf plain.pdf

Current FileOpen permission servers can use a newer client identity. The modern
profile reproduces the plain Settings and DocPerm requests emitted by FileOpen
build 1016 with current Acrobat Reader releases:

    py -3 ineptpdf_fileopen.pyw \
        --fileopen-profile modern \
        --fileopen-settings-envelope plain \
        --fileopen-docperm-envelope plain \
        --trace-dir trace \
        - protected.pdf plain.pdf

Settings and DocPerm envelopes are independently selectable for servers that
use the Nascv=1 envelope. Use --fileopen-build, --acrobat-version, and
--os-build to reproduce a known installed client tuple. Debug traces can
contain document, machine, user, and session identifiers; keep the raw trace
private. When --trace-dir is supplied, the tool also writes redacted JSON
summaries suitable for bug reports.

No support for this script is offered at Apprentice Alf's blog.
